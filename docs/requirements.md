# C4 需求与验收

## 任务摘要

将知识导航、AI 助教、绘图计算、错题本等功能整合到一个界面。至少实现两个模块，并交付工作台、源代码、设计文档及 3–5 分钟演示视频。

课程要求 4–6 人一组，设组长；每位成员都应理解作品中的数学内容。组员与职责由实际参与者填写，不预设或虚构。

## MVP 验收标准（项目拟定）

### 统一界面

- 可以在知识导航和绘图计算之间切换。
- 提供清晰的使用入口、空状态和输入错误提示。
- README 有真实可执行的安装、开发、测试与生产构建说明。

### 知识导航

- 覆盖极限、连续、导数三个基础主题。
- 每个主题包含定义、适用条件、例题及至少一个常见误区。
- 内容经人工数学审查，注明参考资料。

### 绘图计算

- 支持一元函数绘图和可调整的横轴范围。
- 正确处理无效输入、定义域限制、非有限值和间断点。
- 不跨越已识别的间断点连线，不把采样图像解释成证明。
- 至少验证 `x^2`、`abs(x)` 和 `1/x` 三个案例。
- 用户表达式使用受限解析器，不直接用 `eval` 或 `Function` 执行。

## 扩展模块

错题本、AI 助教在 MVP 稳定后讨论。若接入模型服务，密钥仅置于服务端环境变量，不进入前端或 Git。需说明第三方数据发送范围和费用配置。
