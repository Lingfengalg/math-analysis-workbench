# 模块接口契约

唯一实现源：`src/shared/contracts/index.ts`。文档用于解释语义，不复制维护另一套类型。

## PlotRequest

| 字段              | 语义                                                                        |
| ----------------- | --------------------------------------------------------------------------- |
| expression        | mathjs 表达式，不是 LaTeX，长度 1–160；实际可执行语法还需通过 math 层白名单 |
| xMin / xMax       | 有限数，均在 [-10000, 10000] 内，xMin < xMax                                |
| sourceKnowledgeId | 可选，发起绘图的知识卡片稳定 id                                             |

通过 `createPlotLink(request)` 构造 `/plotting?...` 路由，绘图模块通过 `parsePlotSearch` 校验。
不使用 URL 携带密钥、个人信息或大段聊天内容。

## KnowledgeCard

- `id`：唯一、稳定的英文小写连字符标识。
- `topic`：`limit | continuity | derivative`，扩展枚举需同步筛选和测试。
- `definition`、`conditions`、`pitfalls`、`references`：普通文本，不接受 HTML。
- `formula`：LaTeX，只用于展示。
- `examples[].plot`：可选的 PlotRequest；示例文字并不自动解析为函数。
- 内置三张卡片为工程示例，仍需课程团队人工审查并补充精确引用。

### 知识主题导航

`createKnowledgeTopicLink(topic)` 对知识卡片 schema 支持的主题返回 `/knowledge?topic=...`，无效主题（包括错题本的 `other`）返回 `null`。错题本可使用该链接打开对应主题的知识导航；链接只传主题，不传题目、错因或订正内容。链接指向主题筛选，不代表自动匹配到某一具体知识卡片。 反向 `createMistakeTopicLink(topic)` 打开 `/mistakes?topic=...`；错题页校验参数后按主题筛选，新增错题时默认该主题，用户仍可更改。未知主题回退到“全部”；筛选更新 URL 并支持浏览器前进、后退。

## 计算协议

- 请求：`PlotRequest`（函数）或 `SequenceRequest`（数列：`expression` 用 n 表示项序号，`terms` 为 2–1000 的整数）。Worker 消息用 `type: 'plot' | 'sequence' | 'intersections' | 'tangent' | 'taylor'` 区分，成功响应携带对应的 `type`。
- 响应：`{ ok: true, type: 'plot' | 'sequence', data: { points, gaps, asymptotes? } }` 或 `{ ok: false, error }`。
- 函数模式 `points` 为 `[x, y | null][]`，null 表示不可显示的值或启发式断点，图表不得跨 null 连线；数列模式为 `[n, y | null][]`，n 从 1 到 terms 每项一个点，null 表示该项没有有限实数值（数列模式不做启发式断点探测）。
- 数值量级 > 10⁶、复数、非有限值留空。此规则是可视化限制，不等于数学上无定义。
- `gaps` 为留空图像点的计数，不是数学间断点数量。
- `asymptotes` 为函数模式可选的水平渐近趋势候选；它使用窗口内尾部及范围外少量探测点，可能漏检或误判，不构成极限证明。候选值是数值近似，不等于极限值。
- 变量按模式隔离：函数模式只接受 x，数列模式只接受 n，用错变量直接报错。
- 函数模式当前 801 个基础采样点，启发式断点可能额外增加图像点；不承诺精确识别间断、极值或极限。数列模式只采样前 `terms` 项，观察散点不承诺任何收敛性结论。
- Worker 每次请求独立创建、完成/取消后终止；8 秒超时包含首次模块加载，不是性能保证。
- 对比曲线通过同一 `PlotRequest` 协议逐条独立采样（每条曲线各一次请求），与主曲线共享观察区间；曲线条数上限（3 条）、图例与颜色分配属于界面层约定，不进入响应结构。
- 近似交点通过同一 `PlotRequest` 协议成对计算（主曲线与每条对比曲线各一次请求，比较曲线之间不两两计算），响应为 `{ ok: true, type: 'intersections', data: { points } }`。交点为数值近似而非符号求解：按 x 升序扫描，穿越型交点二分求根，切触（相切）或采样漏过的交点可能漏检；两侧不可求值的区间保守跳过；最多返回 8 个交点。

- 切线通过 `{ type: 'tangent', request, x0 }` 消息单独请求，响应为 `{ ok: true, type: 'tangent', data: { slope, value } }`：斜率为 mathjs 符号求导在 x₀ 处的数值（导函数节点仍须通过白名单校验），不构成极限证明；切点处无有限值、不可导或导数超出白名单时返回明确错误。切线直线由界面按 y = value + slope·(x − x₀) 绘制，不进入响应结构。

- 泰勒多项式通过独立消息单独请求：`{ type: 'taylor', request, center, order }`，响应 `{ ok: true, type: 'taylor', data: { coefficients, points } }`。系数为符号求导在展开中心处的数值除以阶乘（阶数 1–8，中心须为有限实数），`points` 为该多项式按观察区间的采样点；任一步求导失败或超白名单时明确报错。此协议只给出近似多项式，不声称收敛或等价。

## 极限互动动画

- 知识导航 `topic=limit` 下的固定教学场景分别为 x² 在 1 附近和 x/|x| 在 0 附近；由 JSXGraph 绘制、Tween.js 插值，不解析用户表达式。滑块范围为 0–100%，左右点到目标的距离从 1 缩小至 0.01，始终不等于零。
- 播放为单次动画，支持暂停、继续、手动调整和重置；离开页面、页面转入后台或启用减少动态效果时停止。动画不自动触发，不记录到本地存储。
- JSXGraph 原生 SVG 渲染器导出当前静态画面。支持 VP8 WebM 录制的浏览器可将固定场景在本地另行录制为视频；该流程不上传数据，切至后台或离开页面会取消录制并释放资源。浏览器不支持时显示提示，仍可导出 SVG。观察值与图像不是数学证明；例题内容仍需课程团队审核。

### 极限动画视频导出方案

- 使用浏览器原生 [MediaRecorder 和 canvas.captureStream](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder)，通过 [isTypeSupported](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/isTypeSupported_static) 检测 VP8 WebM；无法编码时保留 SVG 静态导出，不承诺所有浏览器或设备均支持视频。已在 Chromium 自动测试，其他浏览器和移动设备仍需实测。
- 离屏画面采用 640 × 400、捕获上限 15 帧/秒、约 5.5 秒动画加结尾停留，目标码率 1.5 Mbps；接收的编码数据超过 8 MiB 时停止。编码和逐帧 SVG 栅格化仍可能占用主线程和内存，较慢设备可能跳帧；不上传画面。页面进入后台、离开或用户取消时终止并释放媒体轨道及画布。减少动态效果设置不自动播放页面，但用户主动请求时仍可生成视频。
- [fix-webm-duration](https://github.com/yusitnikov/fix-webm-duration)（MIT）用于补写时长元数据。曾评估 [gif.js](https://github.com/jnordberg/gif.js)（MIT）：提供浏览器 GIF 和 worker 编码，但 GIF 不是请求的可播放视频格式且需要另行维护 worker 资源，因此本阶段不引入；也未引入大型 FFmpeg/WASM。

## 可选数学输入

绘图主表达式与练习数字答案可打开按需加载的 MathLive 编辑器；原有文本输入始终保留。编辑器从空白开始，不尝试把旧表达式自动转成 LaTeX。输出仅接受约定的命令和字符子集，再用 MathLive 的 ASCIIMath 输出转换；显示结果后由用户明确替换。积分、下标、不完整占位符和未知命令被拒绝；绘图结果还必须通过原有 Worker 白名单校验，校验期间原文本变更则放弃覆盖。编辑器不执行用户代码。数列模式变量为 `n`，函数模式为 `x`，数值答案仅允许整数、小数和整数分数并继续交给 Perseus 评分。资源本地打包；不加载 CDN 字体或键盘声音。不能据此声称支持任意 LaTeX、证明或通用符号求解。

## 存储协议

统一使用 `createStorage(key, zodSchema)`，键前缀为 `math-workbench:`。

```json
{
  "schemaVersion": 1,
  "data": {}
}
```

- `read(fallback)`：无记录时返回默认值；损坏、未知版本或无法读取时返回错误，不覆盖原数据。
- `write(value)`：先校验，再写入；存储配额不足时返回错误。
- `clear()`：只清除该模块的键，不调用 `localStorage.clear()` 清除其他模块数据。
- 当前保存绘图默认设置、本地错题本及示例练习记录，没有账号、跨设备同步或数据库。
- 后续升级 schema 时提供明确迁移或导出恢复流程，不能直接丢弃用户数据。

## 错题本存储

错题结构属于模块内部实现（`src/features/mistakes/model.ts`），未进入 `shared/contracts`，其他模块不得依赖它。
若后续需要跨模块引用错题，先在本仓库 Issue 讨论后再迁移为共享契约。

单条错题字段：

| 字段            | 语义                                          |
| --------------- | --------------------------------------------- |
| `id`            | 浏览器本地生成的非空字符串，仅用于列表操作    |
| `title`         | 题目，1–120 字符                              |
| `topic`         | `limit \| continuity \| derivative \| other`  |
| `problem`       | 题目内容，最多 2000 字符                      |
| `mistakeReason` | 错误原因，最多 1000 字符                      |
| `correction`    | 订正与正确思路，最多 4000 字符                |
| `createdAt`     | 创建时间，epoch 毫秒                          |
| `updatedAt`     | 最近更新时间，epoch 毫秒；列表据此倒序        |
| `reviewedAt`    | 最近复习时间；`null` 表示未复习，缺省按未复习 |

存储键为 `math-workbench:mistakes`，当前写入版本 2 信封，兼容读取版本 1；最多 200 条。首次写入时升级信封，不根据旧的复习标记伪造 FSRS 记录。旧版应用无法读取版本 2，因此不会静默丢弃新计划。
写入前统一经 Zod 校验；损坏、未知版本或不可读时只提示并保留原始数据，由用户显式清除，不静默覆盖。
记录只保存在当前浏览器，不含账号、云同步或真实个人信息。

并发写入：每次新增、编辑、删除都先重新读取存储中的最新列表，再做增量修改后写回，并持有 Web Locks 互斥锁
（`math-workbench:mistakes-write`）。其他标签页的写入通过 `storage` 事件同步到当前界面，
因此一个标签页的旧快照不会覆盖另一个标签页的改动。

同一记录在编辑期间被其他标签页修改或删除时拒绝覆盖并保留表单草稿；打开删除确认时会记录该条记录的快照，
确认时在锁内比对最新值，若期间被修改或删除则不执行删除、提示重新确认，避免误删新版本。
读取失败时放弃写入，不覆盖无法解析的原始数据。

`storage` 事件同时同步错误状态：其他标签页写入损坏或版本不兼容的数据时，当前页立即显示读取错误并保持原始数据不动；
数据恢复可读（或被清除）后错误提示自动消失。

### 浏览器兼容性

写入一致性依赖 Web Locks API，按能力探测（`navigator.locks.request` 可调用）而不是 UA 判断，且需要安全上下文（https 或 localhost）。

| 浏览器               | 最低版本 | 说明                     |
| -------------------- | -------- | ------------------------ |
| Chrome / Edge        | 69 / 79  | 支持                     |
| Firefox              | 96       | 支持                     |
| Safari               | 15.4     | 支持                     |
| 不支持或非安全上下文 | —        | 错题本切换为**只读模式** |

只读模式下仍可查看与导出数据，所有写操作按钮禁用，并显示明确提示，而不是退回不安全的并发写入。

### 导出文件格式

```json
{
  "format": "math-analysis-workbench/mistakes",
  "version": 2,
  "exportedAt": "2026-10-29T02:00:00.000Z",
  "items": []
}
```

- `items` 的每项与上方字段一致，包含可选的复习计划，最多 200 条，`id` 不得重复；导入兼容版本 1，导出为版本 2。
- 导入时先 `JSON.parse` 再经 Zod 校验；格式标识、版本、字段或条数不符时整份文件拒绝，不改动现有数据。
- `merge`：按 `id` 去重，重复项保留 `updatedAt` 较新的一条；`replace`：清空后整体导入。
- 导入同样遵循「读最新 → 增量写入」，并受 200 条上限约束。
- 合并时如无计划的输入将按更新时间覆盖有计划的本地记录，拒绝整次合并；替换模式由用户明确确认后替换全部记录。

### FSRS 复习计划

- 每条错题的可选 `schedule` 内保存版本 1、算法 `FSRS-6`、下次到期及上次复习时间（epoch 毫秒）、稳定性、难度、间隔、学习步数、复习次数、遗忘次数、状态与最近评分，所有外部值经 Zod 校验。旧错题没有计划时视为待复习，不创建虚假的历史。
- 自由文本重做的四档自评分别映射 ts-fsrs 的 Again / Hard / Good / Easy；使用 `ts-fsrs` 5.4.2、目标保持率 0.9、关闭随机间隔，按库的默认学习步骤计算。卡片与复习标记在现有错题锁内一次写入；编辑冲突或系统时间倒退时不写入。
- 到期只在页面运行时计算，按设备本地时间展示；不提供通知、参数训练或后台同步。既有复习标记与示例练习自动判分不会更改 FSRS 计划；自评 Again 会保留「仍需复习」的标记语义。

## 示例练习与重做

- 练习是错题模块内部功能，通过 `/mistakes?practice=1` 打开，`topic` 可选择初始主题；题目 ID 和答案为本地示例数据，并非跨模块公共契约。
- 自动评分仅用于内置的固定答案数字题与单选题：数字输入限制为整数、小数或分数、最长 40 字符且分母非零；不执行用户表达式，也不声称支持通用符号等价判断。使用 `@khanacademy/perseus-score` 的数字及单选评分器。
- 作答存储键为 `math-workbench:practice-attempts`，使用版本 1 存储信封；`data.attempts` 最多 2000 条，每条含唯一 `id`、`questionId`、`answer`、`correct`、`answeredAt`（epoch 毫秒）。无法读取或版本不兼容时保留原值，不写入覆盖。
- 练习备份为 `{ "format": "math-analysis-workbench/practice", "version": 1, "attempts": [...] }`，输入文本不超过 100 万字符；导入经 Zod 校验，按 ID 合并，重复 ID 内容不同或超过上限时拒绝整次导入。练习与错题各自备份；导入记录不会自动改写错题状态。
- 同一浏览器标签页间，练习提交、同步与导入/清除由 `math-workbench:practice-operation` 锁串行；练习记录写入再使用 `math-workbench:practice-attempts-write`，错题写入使用原有错题锁。两份存储不是事务：如果作答保存后错题同步失败，可重新同步该题最新有效结果，不新增作答。用户修改过关联错题的题目内容或主题时拒绝自动覆盖。
- 普通自由文本错题的「重做」不自动评分：先输入，再查看原订正并自评是否已掌握；仅保存复习状态，不保存本次输入。保存前会检查错题是否被其他标签页修改，发生冲突则保留原数据。
