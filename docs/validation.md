## 自动化覆盖摘要

- **数学计算与常驻 Worker（56 项）**：19 个单参数实函数（含 `ln`、`lg`、`cbrt`、`sign`、`floor`、`ceil`）、括号指数 `x^(-2)`、实奇次有理分数幂 `x^(1/3)` / `x^(2/3)` / `x^(-1/3)`、常数底指数 `2^x`、安全拦截（赋值/属性访问/`2^100`/`x^x`）、非对称区间关键整数奇点补采（`sin(x)/x`、`(x^2-1)/(x-1)`）、双曲线对比与对称左右差商计算、Worker `requestId` 复用以及取消/超时/异常后的销毁重建与并发恢复。
- **跨模块路由与存储契约（14 项）**：`plot-link`（含对比函数、纵轴范围与差商参数）、`knowledge-link`、`mistake-link` 参数往返与非法回退；版本化本地存储读写、损坏保护与配额异常。
- **知识图谱与知识导航（8 项）**：五大板块 12 张卡片 Schema 唯一性、全部 `relatedIds` 有效非自指、全部示例表达式白名单可编译、全部 LaTeX 公式通过 KaTeX `strict: 'error'` 校验；大小写不敏感全字段检索、单卡聚焦恢复、关联概念跳转与记入错题本链接。
- **函数实验室组件与端到端交互（8 项单测 + E2E）**：来源卡片展示与切换预设自动清理过期 URL 参数、横纵轴区间校验、双曲线对比、差商面板步长逼近、默认偏好保存与损坏存储告警。
- **错题本模块与响应式布局（8 项单测 + E2E）**：初始空状态、4 道数分典型错题载入与持久化、新建/编辑/公式预览/状态切换/二次确认删除、多维筛选搜索、URL 草稿自动弹窗预填、损坏存储保护与确认重置、JSON 安全导入导出，以及 390px 视口下首页/知识导航/绘图计算/错题本均无横向溢出。

## 本次主要修正与优化

- 修复受限表达式对 `x^(-2)`、`x^(1/3)`、`ln(x)` 等常见数分写法的误拒问题，并改用自定义白名单 AST 实数求值器与 `mathjs/number` 解析器。
- 修复从知识卡片跳入绘图页后切换函数仍残留旧来源提示及 URL 参数覆盖默认偏好的状态同步缺陷。
- 新增纵轴显示范围控制，解决 `1/x`、`tan(x)` 在奇点附近纵轴无限拉伸压扁正常曲线的问题。
- 将 `knowledge`、`plotting`、`mistakes` 样式全面迁移至各自的 CSS Modules，清理 `global.css` 遗留模块选择器，并通过 Rolldown `codeSplitting` 消除构建 >500 kB 体积提示。
