## 间断点启发式改进验证记录

日期：2026-10-29。针对 issue #3 的剩余事项（间断点启发式、数值边界与性能），在 PR #5 基础上实现自适应探测与二分定位。以下记录来自实际本地运行，不是预设结论。

### 环境

- Windows 11 x64，Node.js 24.21.0，npm 11.19.0。与 `.nvmrc` 指定的 22.23.4 不一致：本机未安装 nvm 与 22.x 运行时；远端 CI 仍按 22.23.4 执行。
- Playwright Chromium 首次下载失败（网络原因），设置 `PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright` 后安装成功。
- Windows autocrlf 使工作区文件为 CRLF，`npm run format` 归一化为 LF 后未产生额外 diff。

### 改动要点

- `src/shared/math/sample.ts`：相邻有限采样点之间插入 4 个内部探测点；非有限探测点用二分定位有限/非有限边界；异号且幅值明显放大的相邻探测点按极点二分定位；其余按偏离线性插值的保守阈值断线（阈值沿用 0.75 × 局部尺度）。
- 数值边界：二分限 40 次、探测限 4 点，超 10⁶ 的结果留空；默认 801 采样点约 4000 次求值，全部在 Worker 内完成。
- 新增测试：`1/x` 极点不在采样点上定位到 0、`tan(x)` 在 π/2 附近断线、跳跃间断 `abs(x)/x`、偶阶极点 `1/(x-0.25)^2` 且平滑侧不误断、陡峭连续函数（`x^3`、`abs(x)`、`sin(10x)`）不误断、`exp(x)` 超上限留空、1201 最大采样量在 1.5 秒预算内完成。

### 边界

- 仍是启发式，不是符号计算：窄于探测间隔的特征可能漏检；欠采样的高频振荡会被保守地断线（图表以缺口呈现，不会错误连线），可能误判。
- 未覆盖 Firefox、Safari 与完整无障碍审计。
