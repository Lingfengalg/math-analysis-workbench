# 演示脚本（3–5 分钟）

按当前 main 的功能写成，录制前先 `npm ci && npm run dev`。所有数学表述只作为「观察」，不宣称图像即证明。

## 0:00–0:30 开场

- 打开首页，说明这是析知工作台：知识导航、绘图、错题本、练习、数据备份。
- 一句话定位：把「看懂定义」和「发现自己错在哪」连起来，所有数据默认只存本机。

## 0:30–1:30 知识导航

- 进入知识导航，展示一张卡片的定义、条件、例子、常见误区、参考说明。
- 演示搜索「倒过来」命中误区；演示卡片底部的「相关概念」跳到另一张卡并高亮。
- 指出侧栏迷你示意图下方的说明：数值采样，留空不代表已证明间断。

## 1:30–2:30 绘图计算

- 输入 `1/x`，观察虚线标记与数据摘要；强调「疑似间断」而非「证明间断」。
- 输入 `sin`，展示「函数名不能作为数值使用」的提示。
- 打开「最近绘制」下拉，切回上一条表达式并重绘；演示导出 PNG。

## 2:30–3:30 错题本与练习

- 记录一条错题（题目 + 订正），标注错因；演示按错因筛选与分布统计。
- 关联一张知识卡片，点击链接直达知识导航。
- 进入重做：先写思路 → 查看订正 → 选择记忆程度；展示「撤销评分」恢复计划。

## 3:30–4:30 数据备份

- 打开「数据备份」，导出完整备份（说明只在本机下载）。
- 清空后重新导入，展示预览与按模块恢复；说明中途失败会下载快照，不承诺跨键原子性。

## 4:30–5:00 收尾

- 说明 AI 助教仍是规划中：`docs/ai-assistant.md` 记录了服务端设计与验收边界，未配置时不伪造回答。
- 打开 `docs/validation.md` 说明哪些验证真的跑过、哪些仍未覆盖（Pages、真机 Safari、数学内容人工核验）。

## 录制注意

- 不展示任何密钥、Token、个人信息或未获授权的教材内容。
- 终端只保留命令与结果，必要时先清屏。
- 视频与字幕由组员完成，本文件只是脚本，不是已完成的视频。
