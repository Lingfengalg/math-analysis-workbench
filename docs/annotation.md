# 全页面批注层

状态：已实现（Issue #16）。适用于所有路由页面，是跨模块能力，不属于任何单个 feature。

## 目标

把「读」和「记」放在同一个界面里：在知识卡片的定义旁圈重点、在函数图像上标切线与间断点，不必在笔记软件和网页之间来回抄写。

## 使用方式

页面右下角固定一个「批注」按钮：

| 操作        | 说明                                                                   |
| ----------- | ---------------------------------------------------------------------- |
| 开启批注    | 点击「批注」，工具面板展开，画布开始接收指针事件                       |
| 画笔        | 4 色（黑 / 红 / 蓝 / 绿）× 3 档笔宽（细 / 中 / 粗），按住拖动书写      |
| 橡皮        | 点击笔迹即整笔删除（不是像素级擦除，便于撤销）                         |
| 文字        | 点击空白处输入，回车提交，Esc 取消；拖动可移动位置                     |
| 编辑文字    | 点击已有文字重新打开编辑器；清空内容后提交即删除该文字                 |
| 撤销 / 重做 | 面板按钮，或 `Ctrl/Cmd + Z`、`Ctrl/Cmd + Shift + Z`（`Ctrl + Y` 亦可） |
| 清空本页    | 清除当前页面批注（可撤销）                                             |
| 清空全部    | 删除所有页面的批注键，需要二次确认，不影响绘图设置、错题本等模块数据   |
| 关闭批注    | 再点一次按钮，画布不再拦截指针事件                                     |

快捷键（批注开启且焦点不在输入框内）：`P` 画笔、`E` 橡皮、`T` 文字。

## 接入方式

批注层由 `AppLayout` 按当前路由挂载，页面模块无需任何改动：

```tsx
<AnnotationOverlay pageId={location.pathname}>{children}</AnnotationOverlay>
```

新增模块只要注册进导航（`src/shared/navigation/modules.ts`），就自动获得批注能力。批注层放在 `src/shared/annotation/`，因为它被 app 层使用，且不应被任何 feature 反向依赖；放进 `src/features/*` 会违反「模块之间不得互相引用内部实现」的约定。

## 数据结构

坐标一律是**相对批注容器的归一化值（0–1）**，不是像素：

```ts
type Point = { x: number; y: number };

type StrokeItem = {
  kind: 'stroke';
  id: string;
  color: string; // #rrggbb
  width: number; // CSS 像素
  points: Point[];
};

type TextItem = {
  kind: 'text';
  id: string;
  color: string;
  x: number;
  y: number;
  text: string; // 支持换行（Shift + Enter）
};

type AnnotationDoc = { pageId: string; items: (StrokeItem | TextItem)[] };
```

存储的 JSON 由 `shared/storage` 的版本信封包裹：

```json
{
  "schemaVersion": 1,
  "data": {
    "pageId": "/knowledge",
    "items": [
      {
        "kind": "stroke",
        "id": "a1",
        "color": "#dc2626",
        "width": 4,
        "points": [
          { "x": 0.21, "y": 0.33 },
          { "x": 0.28, "y": 0.35 }
        ]
      }
    ]
  }
}
```

## 坐标策略与锚定

坐标一律是归一化值（0–1），但**归一化的参照系取决于绘制位置**：

| 绘制位置                                   | 参照系     | 重排时的行为                         |
| ------------------------------------------ | ---------- | ------------------------------------ |
| 落在带 `data-annotation-anchor` 的内容块内 | 该块的宽高 | 跟随块移动、换行、缩放，仍贴住原内容 |
| 落在内容块之外（页边、块间隙）             | 整页容器   | 只保证随容器缩放，重排后可能错位     |

内容块通过 `data-annotation-anchor` 标记：知识卡片为 `knowledge:<card.id>`，绘图图表为 `plotting:chart`。
绘制时用 `document.elementsFromPoint` 穿透画布找到指针下方的块（画布在最上层，`event.target` 永远是 canvas），
把坐标存成块内归一化值，并在条目上记录 `anchor.key`。

块本身消失时（例如搜索筛选把这张卡滤掉），该条批注**不显示、也不猜测位置**，工具栏给出
「N 条批注锚定的内容不在当前页面，已暂时隐藏」；块重新出现后自动恢复显示。
数据不会被删除，恢复只是重新计算锚点矩形。

旧数据没有 `anchor` 字段，仍按整页归一化渲染，不会因升级而错位或丢失；
本次不迁移历史批注，因此旧批注在重排后仍可能漂移。

代价：批注**不会随函数图象的横轴范围变化而缩放**——这是刻意的取舍，避免重新采样时笔迹漂移。

## 存储契约

| 项       | 值                                                             |
| -------- | -------------------------------------------------------------- |
| 键       | `math-workbench:annotation:<pageId>`，`pageId` 取路由 pathname |
| 校验     | `src/shared/annotation/model.ts` 的 Zod schema                 |
| 上限     | 单笔 ≤ 4000 点，单页 ≤ 2000 条，颜色必须是 6 位十六进制        |
| 写入     | 每次操作后 250 ms 防抖；切页与页面卸载时立即落盘               |
| 失败处理 | 存储不可用或超配额时提示，不静默丢弃                           |

### 不覆盖不可读数据

读到损坏、版本不兼容或无法解析的数据时，批注层**暂停该页的自动保存**并给出提示，不会用空文档覆盖用户原有数据；只有用户显式点击「清空本页」才重置该页存储。该行为有对应测试（`AnnotationOverlay.test.tsx`），也与主分支 `math-workbench:preferences` 曾出现的「不可读设置被直接覆盖」问题保持同一处理原则。

## 跨标签页写入

- 每个页面的写入在 Web Locks 互斥锁 `math-workbench:annotation-write:<pageId>` 内完成，读取最新文档后再合并。
- 落盘使用「增量合并」：只应用本页新增 / 修改 / 删除的条目，不会把整页快照盖回去，因此两个标签页各画一笔都会保留。
- 已被其他标签页删除的条目不会被旧页面写回；同一 id 的并发修改按「后写入者生效」处理（只影响该条，不影响其他条目）。
- 环境不支持 Web Locks（或非安全上下文）时批注切换为只读：入口禁用并给出说明，不回退到不安全的整页写入。
- 等待写入锁时的新修改会并入该页草稿；切页后的旧页保存不会覆盖当前页的画布。
- 刷新 / 关闭时使用同步兜底写入：浏览器不会等待异步锁，此处按增量合并，但无法参与 Web Locks 互斥；若与其他标签页的写入或清空同时发生，仍可能发生竞争，不保证完全无丢失。

## 输入上限与保存失败

- 单条文字最多 500 字符（编辑框 `maxLength` 直接限制），单笔最多 4000 个点，单页最多 2000 条批注；超限时提示，不会先显示后保存失败。
- 保存采用 250 ms 防抖；切页、组件卸载、`pagehide` 与页面切到后台时都会立即落盘，尽力保存最后一次修改，但浏览器异常终止、存储失败或跨标签页竞争时不保证保存成功。
- 保存失败（配额、存储被禁用）时保留未保存草稿，工具栏出现「重试保存」；不会假报成功，也不会静默丢弃。
- 快捷键只在批注模式开启时接管 `Ctrl/Cmd + Z`、`Ctrl/Cmd + Y`、`P`、`E`、`T`；关闭时不影响页面原有快捷键。

## 已知限制

1. **只存本地**：数据在 `localStorage`，不跨设备、不跨浏览器同步。
2. **容量有限**：单域名约 5 MB，长时间书写大量笔迹会逼近上限。
3. **不随图象缩放**：批注绑定页面坐标，不跟随函数横轴范围变化。
4. **文字不自动换行**：需要换行请用 Shift + Enter；不支持二次编辑已提交文字（可删除后重写）。
5. **无导出**：PNG 导出、与错题本联动属于后续扩展，未在本 Issue 范围内实现。
6. **触控未实测**：使用 Pointer Events，理论上支持触屏与手写笔，尚未在真机验收。

## 测试

`src/shared/annotation/*.test.*` 覆盖：

- 模型：非法颜色、空笔迹、空白文字、深拷贝隔离；
- 几何：点到线段距离、命中测试（含笔宽）、坐标换算；
- 历史：撤销/重做顺序、上限截断、新操作清空重做栈；
- 存储：按页往返、损坏数据回退为空文档、`clear` 只影响指定页；
- 组件：默认不拦截指针事件、开启后接管、快捷键切换工具、切页重新加载、不可读数据暂停保存。
