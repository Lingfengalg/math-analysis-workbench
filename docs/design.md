# 设计文档

状态：v0.2 已完成「知识导航」「绘图计算（函数实验室）」「错题本」三大模块及跨模块联动闭环；「AI 助教」保持待开发规划入口。完整开发规范见 [development.md](development.md)，接口约定见 [contracts.md](contracts.md)。

## 目标用户与场景

工科数学分析课程学生在同一工作台中：

1. **读条件**：查阅五大板块核心概念、定理充要前提、正反例与关联概念网络；
2. **看图像**：用双曲线对比（泰勒逼近、夹逼上下界）、纵轴视窗保护与差商割线实验检验直觉；
3. **记错因**：按数分高频思维误区归档错题，关联原知识卡片与反例函数图像反复复盘。

## 技术方案

- React 19 + TypeScript（strict）+ Vite 8；Ant Design 6 与各模块独立 CSS Modules；React Router 8 HashRouter。
- `mathjs/number` 解析 AST + 自定义白名单实数递归求值器，在可复用常驻 Web Worker 内采样；ECharts 6 绘制主曲线、对比虚线、差商割线与观察锚点；KaTeX（`trust: false, strict: 'error'`）渲染公式。
- Zod 4 统一跨模块契约与导入校验；版本化 `localStorage` 分别保存绘图默认偏好与错题本数据。
- Rolldown `codeSplitting` 按 `echarts`、`zrender`、`katex`、`mathjs` 拆分缓存代码块，避免单 chunk 过大。
- Vitest / Testing Library 单元与组件测试（10 个文件 94 项用例），Playwright 真实 Chromium 验证 8 项端到端与移动端无溢出流程，GitHub Actions 自动检查。

## 质量设计

- 输入校验：表达式解析失败、非法横纵轴范围、零步长差商、导入损坏 JSON 均有明确中文反馈。
- 数学正确性：明确区分数值采样/差商观察与严格 ε-δ 证明；对奇次有理分数幂按实奇次根求值以正确呈现 `x^(1/3)`、`x^(2/3)` 等实函数反例。
- 可用性：语义化表单标签、键盘可操作、无障碍图表描述、390px 移动端自适应无整页横向溢出。
- 隐私与数据安全：纯本地存储，损坏数据不静默覆盖，错题支持一键 JSON 导出备份与清空。
- 安全：严禁 `eval` / `Function` 执行用户表达式，KaTeX 禁用 `trust`，不暴露任何模型密钥。
