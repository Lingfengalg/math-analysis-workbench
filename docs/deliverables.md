# 课程交付清单

截止日期：2026 年 12 月 5 日，以教师最终通知为准。

## C4 专项交付

- [ ] 统一界面的工作台，至少两个可用模块。
- [ ] 源代码及完整 README。
- [ ] 与实际实现一致的设计文档。
- [ ] 3–5 分钟演示视频（MP4、1080p、带字幕）。

## 通用五件套

- [ ] 01 作品说明：作品名、选题、真实组员与分工、200 字内简介、使用方式及在线链接，导出 PDF。
- [ ] 02 作品本体：含 C4 专项交付材料。
- [ ] 03 AI 使用日志：工具、关键提示词与回答、人工核验；记录实际发生的错误与纠正，导出 XLSX 或 PDF。
- [ ] 04 分工与贡献表：工作量合计 100%，全组签字，导出 PDF。
- [ ] 05 答辩 PPT：8 分钟，包含演示、数学要点与 AI 使用心得，提交 PPT 或 PDF。

## 打包示例

```text
G组长学号_C4_数学分析学习工作台/
├── 01_作品说明.pdf
├── 02_作品本体/
├── 03_AI使用日志.xlsx
├── 04_分工与贡献表.pdf
├── 05_答辩PPT.pptx
└── 06_过程材料/（选交）
```

由组长打包 ZIP 提交课程教学云平台，在线链接应保证学期末前可访问。
任务书对作品说明的编号存在 `00` 与 `01` 两种表述，本仓库暂按示例结构采用 `01`，提交前向教师确认。

模板只是源材料，不是已经完成的 PDF、视频、XLSX 或签字文件。数学核心文档与答辩需由组员亲自完成和理解。
